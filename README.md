# Desi Hesaplama

Koli ve palet için desi / hacim / ağırlık hesaplayan mobil uygulama (CEVA fiyat listesi ve il bazında bölge dağılımı ile).

- `index.html`: tek dosyalık web uygulaması (tarayıcıda doğrudan açılır)
- `app/`: aynı sayfayı WebView ile saran Android projesi
- `.github/workflows/build.yml`: GitHub Actions ile APK derler (Actions sekmesi → Build APK → Artifacts)

## Bilgisayarda açma

1. GitHub'da **Code → Download ZIP** ile indir ve klasöre çıkar.
2. Windows'ta **`Desi Hesaplama Baslat.bat`** dosyasına çift tıkla. Program, Edge veya Chrome varsa ayrı bir uygulama penceresinde, yoksa varsayılan tarayıcında açılır.
3. Mac'te **`Desi Hesaplama Baslat.command`** dosyasına çift tıkla.

Başlatma dosyası `index.html` ile aynı klasörde durmalıdır. İnternet gerekmez.
