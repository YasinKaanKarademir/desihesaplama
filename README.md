# Desi Hesaplama

Koli ve palet için desi / hacim / ağırlık hesaplayan mobil uygulama (CEVA fiyat listesi ve il bazında bölge dağılımı ile).

- `index.html`: tek dosyalık web uygulaması (tarayıcıda doğrudan açılır)
- `app/`: aynı sayfayı WebView ile saran Android projesi
- `.github/workflows/build.yml`: GitHub Actions ile APK derler (Actions sekmesi → Build APK → Artifacts)
